# CareLink · concept prototype

Clickable prototype for the "One Member, Many Programs" case study. One guided story follows Robert through a shared coordination platform: AI flag → care manager review → specialists → merged plan → member heads-up → one call with AI summary → outcomes.

All names and data are fictional.

- Live demo: GitHub Pages (served from `/docs`)
- Run locally: `npm install && npm run dev`
- Rebuild the demo: `npm run build && rm -rf docs && cp -r dist docs`
